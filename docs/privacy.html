プライバシーポリシー / Privacy Policy

最終更新日 / Last Updated: 2026-02-16

1. 収集するデータ / Data Collection

Andersen-Editor は個人情報を収集しません。 氏名、メールアドレス、位置情報、利用履歴などを開発者サーバーへ送信しません。

Andersen-Editor does not collect personal data. We do not send your name, email, location, or usage data to developer-managed servers.

2. 通信 / Network Communication

本アプリは動作に必須の外部通信を行いません。 編集・保存・表示処理はローカル環境で完結します。

The app does not require external network communication for core functionality. Editing, rendering, and saving run locally.

3. ローカル保存 / Local Storage

  • ユーザーが作成・保存したファイル（例: .mmd）は、ユーザーが指定したローカルパスに保存されます。
  • 一部の設定情報は OS のアプリ設定領域（例: userData）に保存されることがあります。
  • これらのデータはユーザー端末内にのみ存在し、外部送信されません。

4. サードパーティ共有 / Third-party Sharing

開発者は、ユーザーデータを第三者へ販売・共有しません。

We do not sell or share user data with third parties.

5. お問い合わせ / Contact

ご質問は support.html を参照してください。

For questions, please see support.html.

This policy page is prepared for Microsoft Partner Center listing requirements.
