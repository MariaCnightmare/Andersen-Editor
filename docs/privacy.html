プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-02-23

1. 収集する情報 / Data Collection

Andersen-Editor は、個人情報（氏名・メールアドレス・位置情報等）を収集しません。
Andersen-Editor does not collect personal data (name, email, location, etc.).

  • 入力した Mermaid テキスト、図のデータは 端末内で処理されます。
  • 作成したファイル（.mmd/.svg/.png/.pdf 等）は ユーザーが保存した場所にのみ保存されます。

2. 外部通信 / Network Access

基本動作はオフラインで完結します。
The app is designed to work offline.

  • 外部サーバーへの自動送信は行いません。
  • ユーザーが明示的に操作した場合（例: Report a bug でブラウザを開く）に限り、外部ページへ遷移します。

3. 第三者提供 / Third-party Sharing

収集データがないため、第三者提供も行いません。
Since no personal data is collected, no data is shared with third parties.

4. ローカル保存 / Local Storage

アプリ設定（例: UIスケール、言語、オンボーディング表示済みフラグ等）は、端末内のローカルストレージに保存される場合があります。
App settings (UI scale, language, onboarding flag, etc.) may be stored locally on your device.

5. 診断情報 / Diagnostics

問題調査のために「Copy diagnostics」等で診断テキストを取得できる場合があります。これはユーザーの操作によってコピーされるもので、アプリが自動送信することはありません。
Diagnostics can be copied by user action. The app does not upload diagnostics automatically.

6. お問い合わせ / Contact

不具合報告・質問は GitHub Issues からお願いします。
For support, please use GitHub Issues.

GitHub Issues

7. 改定 / Changes

本ポリシーは必要に応じて更新されます。更新内容は本ページに反映します。
This policy may be updated. Changes will be posted on this page.
