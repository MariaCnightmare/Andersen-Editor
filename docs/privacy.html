プライバシーポリシー / Privacy Policy

Andersen-Editor のプライバシーに関する方針です。
This page describes the privacy policy for Andersen-Editor.

Home | Support

要約 / Summary TL;DR

  • データ収集なし / No personal data collection
  • 必須の外部通信なし / No required external network communication
  • ローカル処理 / Data is processed locally on device

収集する情報 / Information we collect

Andersen-Editor は、氏名・メールアドレス・広告ID・位置情報などの個人情報を 収集しません。
Andersen-Editor does not collect personal information such as name, email address, advertising ID, or location data.

外部通信 / Network communication

アプリの主要機能はオフラインで利用できます。常時通信やアカウント登録は不要です。
Core features work offline. No always-on communication or account registration is required.

例外として、ユーザーが明示的に外部リンクを開く操作をした場合（例：Support/Report a bug 等）、 OS の既定ブラウザで外部サイトへ遷移することがあります。
As an exception, when you explicitly open external links (e.g., Support/Report a bug), your default browser may navigate to external sites.

デバイス上の保存 / Local storage

アプリは設定（例：言語、UIスケール、オンボーディング表示済みフラグ等）を ローカルに保存する場合があります。
The app may store settings locally (e.g., language, UI scale, onboarding seen flag).

これらはユーザー体験のための設定であり、外部へ送信されません。
These settings are for user experience and are not transmitted externally.

診断情報 / Diagnostics

アプリ内の「Copy diagnostics」等の機能は、環境情報・エラー要約を ユーザーの操作でコピーするためのものです。
Features like “Copy diagnostics” let you copy environment/error summary by user action.

その内容を共有するかどうかはユーザーの判断に委ねられます。共有する場合は、 個人情報や機密情報（パス、ユーザー名など）が含まれないかご確認ください。
You decide whether to share it. Before sharing, please review to avoid personal/secret information (paths, usernames, etc.).

第三者提供 / Third-party sharing

アプリが収集した個人データを第三者へ提供することはありません （収集自体を行いません）。
We do not share collected personal data with third parties (we do not collect it).

子どものプライバシー / Children

本アプリは特定の年齢層を対象に個人情報を収集しません。
This app does not collect personal information from any age group.

お問い合わせ / Contact

本ポリシーに関するお問い合わせは Support をご覧ください。
For questions about this policy, please see Support.

改定 / Changes

本ポリシーは、必要に応じて更新される場合があります。更新後は本ページで告知します。
This policy may be updated as needed. Updates will be posted on this page.
