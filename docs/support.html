お問い合わせ / Contact 推奨

まずは GitHub Issues にご連絡ください（再現手順が残りやすく、対応が早いです）。
Please contact us via GitHub Issues (best for reproducible reports).

  • GitHub Issues: Open issues

返信目安 / Response time: 数日以内（可能な限り早く対応します）
Within a few days, as available.

不具合報告に含めてほしい情報 / What to include

  • 発生手順（できれば 1→2→3 の箇条書き）
  • 期待した結果 / 実際の結果（スクショがあると強い）
  • OS バージョン（Windows 10/11、ビルド番号）
  • Andersen-Editor のバージョン（画面左下）
  • 可能なら「Copy diagnostics」の内容（後述）

ログ取得 / Diagnostics

アプリ内の Copy diagnostics を使うと、環境情報・エラー要約をコピーできます。
Use Copy diagnostics to copy environment info and error summary.

⚠️ 注意 / Note: 共有前に、個人情報や機密情報（パス・ユーザー名等）が含まれていないか確認してください。
Please review before sharing to avoid personal/secret information.

よくある質問 / FAQ

  • Q. オフラインで使えますか？
    A. はい。基本機能はローカルで動作し、常時通信は不要です。
    Yes. Core features work locally; no always-on network required.
  • Q. Mermaid のエラーはどこで確認できますか？
    A. 右下の Problems に表示されます。
    Check the Problems panel.
  • Q. 図が画面に収まりません。
    A. Fit（Zoom Fit）で中央・収まり表示にできます。
    Use Fit to center and fit the diagram.
  • Q. MS Store 版で Pro 購入ができません。
    A. 現在ストア版の購入機能は準備中です（編集機能は Free で利用できます）。
    Purchases are currently not available in the Store build (editing is available in Free).

既知の制限 / Known limitations

  • GPU / 描画環境により、フォントやレンダリングが異なる場合があります。
    Rendering may differ depending on GPU/graphics environment.
  • 大規模な図（ノード数が非常に多い）は描画に時間がかかることがあります。
    Very large diagrams may render slower.

プライバシー / Privacy

No personal data collection. See the Privacy Policy for details.
