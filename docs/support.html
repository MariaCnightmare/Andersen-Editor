サポート / Support

Andersen-Editor の問い合わせ先、FAQ、既知の問題、ログ取得方法を掲載しています。

問い合わせ先 / Contact

  • GitHub Issues: https://github.com/MariaCnightmare/Andersen-Editor/issues
  • 返信は GitHub 上で行います。 / Support responses are provided via GitHub.

FAQ

Q. ファイルはどこに保存されますか？ / Where are files stored?

A. ユーザーが指定したローカルパスに保存されます。クラウド送信は行いません。

Q. オフラインで使えますか？ / Can I use it offline?

A. はい。主要機能はローカルで動作します。

Q. Parse エラー時はどうなりますか？ / What happens on parse errors?

A. 最後に成功したプレビューを保持し、Problems パネルにエラー内容が表示されます。

既知の問題 / Known Issues

  • 複雑な Mermaid 記法では、変換後に手動調整が必要な場合があります。
  • 環境依存でフォント表示やレンダリング差異が出ることがあります。
  • 最新の既知問題は GitHub Issues を確認してください。

ログ取得方法 / How to Collect Logs

  • アプリ内メニューの診断機能（例: Copy diagnostics）を利用し、Issue に貼り付けてください。
  • 問題再現手順、使用OS、アプリバージョンを併記してください。
  • 個人情報や機密情報が含まれる場合は、投稿前に必ずマスクしてください。
