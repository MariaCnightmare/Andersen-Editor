サポート / Support

問い合わせ窓口は GitHub Issues です。/ Support is handled via GitHub Issues.

GitHub Issues

不具合報告のテンプレ / Bug report template

  1. 再現手順（できれば最小手順）
  2. 期待した結果 / 実際の結果
  3. スクリーンショット（可能なら）
  4. アプリのバージョン（画面左下など）
  5. OS（Windows 10/11）
  6. 診断情報（取れる場合）

※ Issue に貼る情報は、あなたが公開して良い範囲に留めてください。

診断情報の取得 / How to get diagnostics

  • アプリ内の Copy diagnostics を使用（ある場合）
  • Problems パネルに表示されたエラー文をコピー
  • 再現に必要な Mermaid の最小サンプルを添付

FAQ

  • Q. オフラインで使えますか？
    A. はい。基本はローカル完結です。
  • Q. 構文エラーでプレビューが消えます。
    A. Problems を確認してください（最後に成功したプレビューを保持する設計です）。
  • Q. テンプレートから始めたい。
    A. File → 新規 から Workflow / Org chart / Infra を選べます。
  • Q. 図が画面外に行きました。
    A. Fit / Zoom Fit を使って表示を戻してください。

セキュリティ / Security

脆弱性の疑い（任意コード実行など）がある場合は、Issue に機密情報を書かず、まずは最小情報で連絡してください。
If you suspect a security issue, avoid posting sensitive details publicly; report with minimal info first.
