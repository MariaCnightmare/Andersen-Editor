Mermaid テキストとGUIを往復できる図エディタ
Mermaid + Visual Diagram Editor

Andersen-Editor は、Mermaid を直接編集しながら GUI でも同時に編集できる Electron アプリです。
Andersen-Editor is an Electron app for bidirectional Mermaid text and GUI editing.

ダウンロード / Download GitHub Repository

主な機能 / Key Features

双方向同期 / Bi-directional Sync

テキスト編集とGUI編集が同期し、同じ図を異なる操作で扱えます。

Problems表示 / Error Visibility

構文エラー時も最後に成功したプレビューを維持し、問題を明示します。

多形式出力 / Export Formats

Mermaid, SVG, PNG, PDF, MODEL JSON に対応したエクスポート。

ローカル実行 / Local-first

データ処理はローカルで完結し、外部サーバー連携を前提としません。
